# Contribute to Map of Proofs in Physics

Help improve our guide to theorems, conjectures, open questions, proofs and proof resources in
mathematical physics and quantum information. You do not need to write code
or edit the database.

Choose a contribution:

- [Suggest a theorem, conjecture, or open question](https://github.com/LeanQIQCMap/mpqi-contributions/issues/new?template=new-result.yml)
- [Share progress or a proof](https://github.com/LeanQIQCMap/mpqi-contributions/issues/new?template=progress.yml)
- [Add a review, explanation or Lean resource](https://github.com/LeanQIQCMap/mpqi-contributions/issues/new?template=review-resource.yml)
- [Correct an entry](https://github.com/LeanQIQCMap/mpqi-contributions/issues/new?template=correction.yml)

Search [existing submissions](https://github.com/LeanQIQCMap/mpqi-contributions/issues) before opening another. A GitHub
account is required to submit; you do not need repository access or an invitation.

## Public submissions

Your submission, GitHub username, attachments and discussion are public
immediately. Closing an issue does not make it private. Please do not include
private email addresses, confidential manuscripts or personal information.
This repository does not provide private submissions.

## What happens next?

Maintainers check for duplicates, inspect sources and prepare proposed changes.
They may ask for clarification. Substantive updates receive independent review
before publication. Accepted contributions receive the requested acknowledgment,
separately from original authorship and reviewer credits.

A submission does not automatically enter the Map. Proposed proofs, established
solutions, partial progress, numerical evidence and reviews remain distinct.
Lean resources are surveyed through links and documentation; no external Lean
code is run or certified by the Map.

## Following your submission

- **new**: awaiting initial inspection.
- **needs-information**: waiting for sources or clarification.
- **under-review**: sources and proposed changes are being reviewed.
- **accepted**: approved for inclusion, awaiting publication.
- **published**: the update is public; the closed issue links to it.
- **duplicate** or **declined**: closed with an explanation.

These labels describe the editorial process, not mathematical correctness.
Only maintainers decide acceptance and publication. Read the
[contribution guide](CONTRIBUTING.md) and [editor guide](EDITOR_GUIDE.md).

## Reuse and credit

Repository-authored documentation and original submission wording are offered
under [Apache 2.0](LICENSE), matching the Map's existing repository license.
Third-party papers, quotations and linked resources keep their own terms and
authorship. Prefer links and your own summaries to pasted copyrighted text.

This repository contains public intake and editorial guidance. The website
implementation, private working notes and unpublished editorial drafts are
managed separately.
